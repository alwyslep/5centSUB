# 클라우드 공급자 조사

조사일: 2026-09-20  
상태: **공급자 미확정**

## 결론

원본 4시간 오디오를 전용 전사 API에 그대로 보내는 방식으로는 미화 5센트 상한을
만족할 수 없다. 다음 비용은 번역·저장·재시도 비용을 포함하지 않은 전사 단독의
하한이다.

| 후보 | 공식 단가 | 4시간 전사 단독 계산 | 판정 |
| --- | ---: | ---: | --- |
| Groq `whisper-large-v3-turbo` | $0.04/시간 | $0.16 | 상한의 3.2배 |
| OpenAI `gpt-4o-mini-transcribe` | $0.003/분 | $0.72 | 상한의 14.4배 |
| Google Gemini 전용 Transcribe | 약 $0.005/분 | 약 $1.20 | 상한의 24배 |

따라서 이 프로젝트는 원본 길이가 아니라 실제로 클라우드에 보내는 음성 길이,
모델 입출력 토큰, 번역 출력 토큰, 재시도 비용을 합산한 뒤 요청을 허용해야 한다.
현재 `BudgetLedger`의 사전 승인과 실제 청구 기록 계약이 이 요구를 지킨다.

## Gemini Batch 후보

Gemini Batch API는 대량 비동기 요청을 표준 상호작용 API 비용의 50%로 처리하며,
목표 완료 시간은 24시간이다. 이 방식은 저지연 서비스가 아니라 장시간 오프라인
배치 처리 후보로만 적합하다.

일반 Gemini 모델의 오디오 입력·텍스트 출력 가격은 모델별·시점별로 변한다. 음성
구간 축소 후의 실제 입력 오디오 토큰과 전사·번역 출력 토큰이 아직 없으므로,
현재 5센트 달성 가능성을 숫자로 주장하지 않는다. 짧은 권리 확보 샘플로 실제
사용량을 측정한 뒤에만 견적식을 고정한다.

## 과거 실험 수치의 해석

외부 참고 프로젝트의 SNOS-295 Hybrid AQD 실행에는 Batch ASR ₩48.5, 번역
₩19.6, 합계 ₩68.1이라는 실행 로그가 있다. 이후 보관된 Hybrid ASR 원시
응답 33개를 합산하면 입력 178,668, 출력 75,154 토큰이며, Batch 단가로
$0.0359463 = ₩48.5275가 재계산된다. 번역의 ₩19.60065는 보관 파일의
`estimated_*` 토큰(입력 39,350, 출력 32,180)에 따른 추정값이다.

따라서 합계는 $0.0504653 = ₩68.1282이며, 5centSUB의 $0.05 상한을 만족했다는
근거가 될 수 없다. 같은 외부 작업 트리에 남은 1차 Adaptive AQD 원시 응답은
149,167 입력 토큰과 66,976 출력 토큰을 보인다. 표준 단가로 환산한
$0.06256065(약 ₩84.5)와 Batch 50% 단가로 환산한 $0.031280325(약 ₩42.2)를
구분해야 한다. 자세한 검증 수준과 재현성 요구사항은
[`PROJECT_FOUNDATION.ko.md`](PROJECT_FOUNDATION.ko.md)를 따른다.

## 최신 12편 벤치마크의 단가 불일치

같은 참고 프로젝트에는 12편의 최신 벤치마크 증적도 존재한다. ASR 원시
응답 280개에서 합산한 1,562,277 입력 토큰과 622,406 출력 토큰은 Batch
단가로 $0.30389257 = ₩410.2550을 재현한다.

번역 usage는 단일 형식이 아니다. 10편은 요청별 공급자 응답의 `cost` 필드를
보관하며 그 합계는 $0.17986041이고, 2편은 집계 usage와 계산 비용
$0.02336936만 보관한다. 이 증적들을 합친 번역 비용은 $0.20322977이며,
ASR을 더한 $0.50712234는 혼합 증거 수준의 참고값이다.

별도의 마스터 보고서는 번역 $0.678091, 전체 $0.981984를 제시하지만, 동일한
번역 토큰에 처음 2편은 $0.14/M·$0.28/M, 나머지 10편은
$0.25/M·$0.50/M의 서로 다른 단가를 적용한다. 따라서 이 보고서는 비용
분포 참고자료로만 사용하며, 현재 가격이나 단일 청구 영수증의 근거로 사용하지
않는다.

## 사용·보안 게이트

- 무료 Gemini API/AI Studio 서비스는 입력·출력이 제품 개선과 사람 검토에 사용될
  수 있으므로 원본 미디어나 민감한 자막에 사용하지 않는다.
- Gemini API 약관은 유료 서비스, 사용 가능 지역, 보호 장치 우회 금지, 생성
  콘텐츠에 대한 사용자의 법적 책임을 요구한다. 실제 공급자 도입 전 프로젝트의
  배포·사용 방식이 약관에 맞는지 확인한다.
- 입력 미디어의 저작권·처리 권한과 각 공급자의 허용 사용 정책을 작업 시작 전에
  확인한다. 정책을 우회하는 안전 설정이나 재시도 전략을 구현하지 않는다.
- API 키·원본 파일·클라우드 요청 본문·응답 본문·계정 사용량은 Git에 넣지 않는다.

## 다음 검증 순서

1. 후보 공급자의 현재 API 모델 ID, 지역, 유료 계정 요건을 다시 확인한다.
2. 1~5분의 권리 확보 샘플로 전사와 번역을 각각 한 번만 실행한다.
3. 응답의 실제 사용량과 청구액으로 분당·토큰당 견적식을 만든다.
4. 음성 구간 축소 전후의 비용과 자막 누락률을 비교한다.
5. 4시간 예상 총액에 번역·재시도 여유분까지 넣어 5센트 이하일 때만 장시간
   작업을 허용한다.
