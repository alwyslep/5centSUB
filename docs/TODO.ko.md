## 작업 원칙

- 각 작업은 `feature/`, `fix/`, `docs/` 브랜치에서 수행하고, 검증 후 PR로 `master`에 병합한다.
- API 키, 미디어, 생성 자막, 원시 요청·응답, 사용량 기록은 커밋하지 않는다.
- 외부 프로젝트의 코드는 라이선스와 출처가 확인되기 전까지 복사하지 않는다.
